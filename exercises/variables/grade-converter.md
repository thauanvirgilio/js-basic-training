# Converting a numeric grade into a letter

```js
let grade;
let conversion;

grade = 99;


if (grade >= 90) {
    conversion = "A";
} else if (grade >= 80) {
    conversion = "B";
} else if (grade >= 70) {
    conversion = "C";
} else if (grade >= 60) {
    conversion = "D";
} else {
    conversion = "F";
}
```
